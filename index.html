C Equation Solver Library

A modular C framework for AST parsing, evaluation, symbolic calculus, and numerical integration.

Overview

EqSolver C is a lightweight C library that parses single-variable mathematical expressions into an Abstract Syntax Tree (AST).

The tree engine provides numeric evaluation $y = f(x)$, symbolic differentiation $\frac{dy}{dx}$, rule-based symbolic integration $\int f(x) dx$, and numerical integration using Simpson's 1/3 Rule.

Capabilities

Supported Operations:

  • Operators: Addition (+), Subtraction (-), Multiplication (*), Division (/), Power (^)
  • Functions: Exponential function (exp(...))
  • Operands: Constants (e.g., 5, 3.14) and single variable (e.g., x)
Feature Method / Engine Functionality
Infix Parsing Shunting-Yard algorithm Converts "3 * x^2 + exp(x)" $\to$ AST
Numeric Evaluation Recursive AST Traversal Computes $y = f(x)$ given $x$
Symbolic Differentiation Product, Quotient, & Chain Rules Constructs $\frac{dy}{dx}$ derivative tree
Symbolic Integration Pattern matching & rule resolution Generates antiderivative AST $\int f(x) dx$
Numerical Integration Simpson's 1/3 Rule Definite integral $\int_{a}^{b} f(x) dx$ over $n$ subintervals

Architecture & Expression Tree

Equations are represented in memory using a binary Node tree. Operators form internal branch nodes, while constants and variables exist as leaf nodes.

The Node Structure

typedef enum {
    NODE_CONST, NODE_VAR, NODE_ADD,
    NODE_SUB,   NODE_MUL, NODE_DIV,
    NODE_POW,   NODE_EXP
} NodeType;

typedef struct Node {
    NodeType type;
    double val;            /* Active if type == NODE_CONST */
    char var_name;         /* Active if type == NODE_VAR */
    struct Node *left;     /* Left sub-tree / operand */
    struct Node *right;    /* Right sub-tree / operand */
} Node;

API Reference

1. Parser Interface (parser.h)

Node* parse_expression(const char* expr);

Parses an infix mathematical equation string and returns the root pointer to the AST.

2. Tree Evaluation (expr.h)

double evaluate(Node* node, double x_val);

Recursively evaluates the AST by substituting x_val for variable nodes.

3. Calculus Functions (expr.h)

Node* differentiate(Node* node, char var);

Constructs a new AST representing the symbolic derivative with respect to var.

Node* integrate(Node* node, char var);

Constructs a new AST representing the symbolic antiderivative with respect to var.

double integrate_numerical(Node* root, double a, double b, int n);

Calculates the definite integral $\int_{a}^{b} f(x) dx$ using Simpson's 1/3 Rule with n subintervals.

4. Utilities & Memory (expr.h)

void print_inorder(Node* node);  /* Prints infix equation to stdout */
void free_tree(Node* node);       /* Deallocates dynamic memory for AST */
Node* copy_tree(Node* node);      /* Creates a deep copy of an AST */

Symbolic Integration Rules

Term Pattern Integration Rule
Constant ($c$) $\int c \, dx = c \cdot x$
Variable ($x$) $\int x \, dx = 0.5 \cdot x^2$
Power Rule ($x^n$) $\int x^n \, dx = \frac{x^{n+1}}{n+1} \quad (n \neq -1)$
Exponential ($\exp(x)$) $\int e^x \, dx = e^x$
Scaled Exponential ($\exp(c \cdot x)$) $\int e^{c \cdot x} \, dx = \frac{1}{c} e^{c \cdot x}$
Linear Sum ($\int (f \pm g)$) $\int f \, dx \pm \int g \, dx$

Quick Start & Example

#include <stdio.h>
#include "expr.h"
#include "parser.h"

int main(void) {
    const char* equation = "3 * x^2 + exp(x) + 5";
    
    // 1. Parse String to AST
    Node* root = parse_expression(equation);

    // 2. Symbolic Integration
    Node* integral = integrate(root, 'x');
    printf("∫ f(x) dx = ");
    print_inorder(integral);
    printf(" + C\n");

    // 3. Evaluate Symbolic Definite Integral [0, 2]
    double F_b = evaluate(integral, 2.0);
    double F_a = evaluate(integral, 0.0);
    printf("Definite Integral (Symbolic): %.4f\n", F_b - F_a);

    // 4. Numerical Simpson's Integration [0, 2]
    double num_result = integrate_numerical(root, 0.0, 2.0, 1000);
    printf("Definite Integral (Simpson's): %.4f\n", num_result);

    // 5. Cleanup
    free_tree(root);
    free_tree(integral);

    return 0;
}
